## Scope

These regulations apply to generation companies connected with the grid, except distributed generators.

The regulations establish technical standards and requirements relating to grid connectivity and interconnection of generation facilities.

---

## Application for Interconnection

A generation company seeking interconnection is required to apply to the appropriate transmission or distribution licensee for interconnection and execution of the relevant connection agreement.

The application must be accompanied by the required information and data and an undertaking regarding compliance with the applicable requirements.

---

## Technical Compliance

Generation facilities and associated equipment are required to comply with the applicable Connection Code contained in the Grid Code or the applicable Distribution Code.

An applicant is required to demonstrate compliance with the applicable Connection Code at the application stage.

The generation company must continue to comply with the applicable Grid Code or Distribution Code during operation.

---

## Relevance to Renewable-Energy Project Assessment

For a utility-scale solar PV project, these regulations are relevant when assessing:

1. Whether the proposed generation facility falls within the applicable grid-connectivity framework.
2. The requirement to apply to the appropriate transmission or distribution licensee.
3. Information and data required as part of the interconnection application.
4. Compliance with the applicable Connection Code.
5. Compliance with the Grid Code or Distribution Code during operation.
6. The technical and regulatory requirements that should be considered before grid connection.

---

## Evidence Limitations

This source establishes the regulatory framework for grid connectivity. It does not by itself establish that a particular project has available grid capacity, a specific connection point, or guaranteed interconnection.

Project-specific grid capacity and connection feasibility require project and network information and, where applicable, further technical studies.
